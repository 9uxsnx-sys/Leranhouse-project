# Playgrounds

> Interactive learning elements on Koodook.

---

Playgrounds are interactive, AI-generated elements that let you experiment and learn by doing.

## Examples

- Code playgrounds --- write and run code in the browser
- Interactive diagrams --- manipulate visual elements
- Sandbox environments --- experiment with configurations

## Access

Playgrounds are linked to courses and lessons. Click the playground link to open it in a new view.
