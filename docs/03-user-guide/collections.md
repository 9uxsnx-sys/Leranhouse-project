# Collections

> Course bundles on Koodook.

---

Collections group multiple courses together into a bundle. This is useful for:
- Learning paths (e.g., "Web Development Fundamentals")
- Course series (e.g., "Python 101, 102, 103")
- Thematic bundles (e.g., "Data Science Toolkit")

## Browsing Collections

The **Collections** page shows all available collections.

## Collection Detail

Clicking a collection shows:
- Collection name and description
- List of included courses
- Combined progress if enrolled in multiple courses
