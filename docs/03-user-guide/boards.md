# Boards

Boards are collaborative canvases that open in their own full-screen page. They are shared by link.

## Opening a board

1. Sign in to the organization.
2. Open the board link you received.

The board page requires authentication. If the board does not exist or your account has no access, the page shows "Board not found or access denied." Boards are not indexed by search engines.

## Canvas tools

The left toolbar switches the active tool. The same toolbar holds the draw thickness control.

| Tool | Use |
|---|---|
| Select | Select and move existing blocks |
| Pan | Move the canvas |
| Draw | Freehand drawing at three thicknesses |
| Card | Add a content card |
| Frame | Add a frame group |
| Note | Add a sticky note |
| To-do | Add a checklist block |
| Sticker | Add a sticker |
| YouTube | Embed a YouTube video |
| AI playground | Generate an interactive block |
| Activity | Embed a course activity |
| Embed | Embed custom HTML |
| Webpage | Embed a web page |
| Podcast | Embed a podcast |

The board title bar shows the board name and a back action.

## Collaboration

| Feature | Behaviour |
|---|---|
| Live presence | Avatars of everyone currently on the board |
| Remote cursors | Other people's pointers move in real time |
| Ephemeral chat | A temporary chat panel for the session |
| Zoom | Zoom controls for the canvas |
| Auto-save | Edits are written to the shared board state |

Changes appear for all participants without refreshing. The canvas supports dragging and resizing blocks; selection handles appear on the active block.

## Interactive blocks

Boards can embed course activities, podcasts, videos, web pages and AI playgrounds. An embedded activity opens with the same access rules as the course it belongs to.
