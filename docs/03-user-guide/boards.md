# Boards

> Collaborative whiteboards on Koodook.

---

Boards are real-time collaborative whiteboards powered by Yjs. Multiple users can work on the same board simultaneously.

## Features

- **Real-time collaboration** --- changes appear instantly for all users
- **Drawing tools** --- write, draw, add shapes
- **Text boxes** --- add notes and labels
- **Export** --- save boards as images

## Use Cases

- Brainstorming sessions
- Mind mapping
- Collaborative note-taking
- Visual explanations in courses
