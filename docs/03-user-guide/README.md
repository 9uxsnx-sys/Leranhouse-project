# User Guide

This guide covers the organization site from a learner's point of view: browsing content, taking courses, listening to podcasts, joining communities and managing your account.

## Navigation

The side menu contains:

| Item | Destination |
|---|---|
| Home | Organization home with trending courses and podcasts |
| Courses | Course catalogue |
| Collections | Bundles |
| Communities | Discussion spaces |
| Podcasts | Audio catalogue |
| Progress | Your enrolled courses and their status |

Communities and Podcasts appear when the organization enables them; Collections appears unless it is explicitly disabled. Administrators also see a **Dashboard** link. The bottom of the menu holds the language switcher, the help menu and your profile box.

The store is a separate page at `/store`; it does not have a menu entry.

## Access at a glance

| Mode | What it means for you |
|---|---|
| `public` | Open to everyone; add it to your progress to track it |
| `users_only` | Visible only inside a linked user group |
| `paid` | Product page is visible; content needs a purchase |
| Draft | Not available to learners |
