# Certificates

> Earning and verifying certificates on Koodook.

---

## Earning a Certificate

Some courses offer certificates upon completion. Requirements vary by course:
- Complete all lessons
- Pass all knowledge checks
- Achieve a minimum score on assignments

When you meet the requirements, the certificate is automatically issued.

## Viewing Certificates

Your certificates are available on the **Certificates** page.

## Certificate Details

Each certificate shows:
- Course name
- Your name
- Completion date
- Organization name
- Unique verification code
