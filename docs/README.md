## Project Context

- **Platform Name**: Koodook
- **Codebase**: Learnhouse v1.2.0 (fork)
- **Tech Stack**: Next.js 16 (frontend), FastAPI (backend), PostgreSQL (database), Docker (infrastructure)
- **Business Model**: Pay-to-access learning platform with Chargily Pay v2 for Algerian payments (EDAHABIA/CIB)
- **Development Branch**: `feat/learnhouse-1.2.0-custom`
