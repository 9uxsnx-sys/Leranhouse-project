# Course Management Overview

> How to create, edit, and manage courses on Koodook.

---

## Accessing Course Management

1. Log in as an admin
2. Navigate to **Dashboard** (`/orgs/[orgslug]/dash/`)
3. Click **Courses** in the sidebar
4. Click a course to open the course editor

## Course Editor Tabs

The course editor has 7 tabs:

| Tab | Purpose |
|-----|---------|
| **General** | Name, description, difficulty, thumbnail, certificate toggle |
| **Content** | Module and lesson structure |
| **Access** | Who can access the course (Public, Users Only, Paid) |
| **Certification** | Certificate design and passing criteria |
| **Contributors** | Adding co-authors and instructors |
| **SEO** | SEO metadata and social preview |
| **Analytics** | Course engagement and performance data |

## Course List

The dashboard course list shows all courses in your organization with:
- Course thumbnail and name
- Module and lesson counts
- Published/unpublished status
- Search and filter options
- 3-dot menu per course with **Delete** and **Clone** options

## Editor Layout

The course editor uses a clean layout with no right sidebar. Each tab has an inline **action row** at the top:

```
[👁 Preview]                    [Save] [Publish/Unpublish]
```

- **Preview** (left) — opens the course in a new tab as a user would see it
- **Save** (right) — white bg when saved, black bg when unsaved changes exist
- **Publish/Unpublish** (right) — toggles the course published state

The page scrolls naturally (no inner scroll containers), matching the rest of the platform.

## Creating a Course

1. Click **New Course** button
2. Fill in the basic information
3. Save — the course is created in draft mode
4. Add modules and lessons in the **Content** tab
5. Configure access in the **Access** tab
6. Publish when ready
