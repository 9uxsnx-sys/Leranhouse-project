# Contributing to Koodook

> Welcome to the Koodook contributing guide. This section covers everything you need to know to contribute effectively to the platform — from setting up your environment to submitting your first pull request.

Koodook is a pay-to-access learning management system built on [Learnhouse](https://github.com/learnhouse). The project uses **Bun**, **FastAPI (Python)**, **Next.js (React)**, and **PostgreSQL**. Contributions of all kinds are welcome, whether you're fixing a bug, adding a feature, improving documentation, or helping with code reviews.
